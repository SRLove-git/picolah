# DeepSeek Fetch 修复与线上验证 — 2026-11-05

本次修复已发布到线上 crawler；网站容器、生产环境变量、挂载与无关运行文件保持不变。

## 改动

- `crawler/package.json` 使用 `tsx --test "src/**/*.test.ts"` 自动发现测试，纳入 Fetch、Markdown 商品解析和双源核验测试。
- 修正本地两个旧 Amazon 测试样本：提供与 ASIN 绑定的在售新品购买区域，继续拒绝仅有通用 JSON-LD 的 Amazon 报价。发布包同时更新过期的相关测试字段，未部署本地无关功能。
- Fetch 区分鉴权失败、余额不足、策略拒绝、来源失败、超时、限流和服务端错误，并保留 HTTP 状态。日志只记录受控错误码和数值状态，不记录上游错误正文或密钥。
- 已发现的商品链接可以在其他初始页面尚未结束时进入空闲 worker。普通尾部候选仍等待初始页面完成，保证慢目录页发现的商品链接保有核验名额。
- 保留并发 3、每域名最多 2 页、通常最多 8 页、零结果时最多 12 页、共享最多 2 次短 HTML 重试的限制。链接只跟进一跳。
- 保留双源价格/规格冲突拒绝规则，以及 HTML 核验失败不能恢复未确认 Markdown 报价的规则。

## 验证

- 本地：196 项 crawler 测试全部通过；TypeScript 检查通过；`git diff --check` 通过。
- 线上候选镜像：168 项全量测试与类型检查通过。镜像保留线上既有代码，因此测试数量与包含额外本地工作的工作区不同。
