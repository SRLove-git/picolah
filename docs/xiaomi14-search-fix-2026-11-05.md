# 小米 14 搜索修复 — 2026-11-05

## 问题与修复

生产搜索 `小米14`能正确归一化为 `Xiaomi 14`，但原流程现场检查 12 页后返回零报价。问题出在候选选择：评测、价格历史、翻新商品和无效模板链接占用有限的抓取名额，而真实商家的非标准商品路径排名靠后。

- 不再因为 URL 带 `/product/` 就跳过评测、比价和翻新商品过滤；保留正常商品标题中的 customer reviews。
- 提高准确型号商品路径的优先级，包含 `.html` 和其他商家路径，不绑定特定网站或写入固定报价。
- HTML、Markdown 和商品变体链接均先过滤 `undefined`、`null`、目录等无效候选，再分配每域名两个名额；保留分类目录下的实际 `/products/` 购买链接。
- 兼容商家使用的 `Xiaomi Mi 14` 名称，继续排除 14 Pro、14 Ultra、14T、Redmi 和其他代次。
- 库存、币种、型号和 Fetch/HTML 冲突校验保持不变。Etoren 的 Fetch 在售价格与 HTML 缺货内容不一致，仍不作为有效报价。
