# Picolah accessory icons v2

These transparent raster icons were generated as one Image 2.5 visual family for the capybara wardrobe.

- Canvas: 512 x 512 PNG with alpha
- Direction: soft 3D clay-toy forms, subtle paper-fiber texture, muted macaron colors
- Usage: wardrobe previews and wearable overlays in `CapyAccessoryArt.tsx`
- Source reference: the existing Picolah capybara mascot and wardrobe UI

The original generated masters remain in the local Codex generated-images cache. These project copies are resized for shipping.
